# Custom Data Splits MLB Hitter Report Cards

## Project Overview
The goal of this project is to create simple yet data-rich graphics that provide a comprehensive view of MLB hitter statistics, including both standard and advanced metrics, for custom date ranges. These graphics serve as a fast and efficient tool for evaluating hitters, designed specifically for use by coaches and analysts.

Whether a hitter has made a mechanical adjustment to their swing, implemented a new swing decision strategy, or is recovering from an injury, these cards offer valuable insights into their performance.

## Features
### Standard Player Cards
Comprehensive single-page visualizations displaying key batting metrics with percentile rankings compared against league-wide distributions.
### Platoon Split Cards
Butterfly/tornado-style charts that display a hitter's performance against left-handed and right-handed pitchers side by side. LHP stats appear on the left, RHP stats on the right, providing immediate visual comparison of platoon advantages and vulnerabilities across 14 key metrics.

## How to Use
This project is designed to run through the main.ipynb file, where users can input custom arguments to generate hitter cards. You can choose between standard cards or platoon split cards depending on your analysis needs.
Any pull requests aimed at improving aspects such as load times, file structure, or overall efficiency are highly appreciated.
